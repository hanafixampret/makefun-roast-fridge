One line roasting my own fridge, for the [One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521) bounty on make.fun.

`main.ts` writes a single roast line to `/output/entry.txt`:

> My fridge's ice maker sounds like it's chewing gravel at 3 a.m., then drops a single cube like a tip for the noise.

Run it with Node 22.18+:

```sh
node main.ts
```
